Title Suggestions

Submissions from the "suggest a title / flag inaccurate" box on the public site. Apply title updates the title on the live site right away and queues the fix so the next scheduled data run bakes it in permanently. Dismiss just clears a submission from this list without changing any data.
Apply/Dismiss write directly to the GitHub repo, so they need a token. Create one at github.com/settings/personal-access-tokens/new — Repository access: only cincinnati-council; Permissions: Contents → Read and write. It's stored only in this browser (localStorage), never sent anywhere but GitHub's API.
